# Claude向けの入口ひな形

導入時にこの注意書きを外し、既存CLAUDE.mdへ必要な内容だけを統合する。対応するAGENTS.mdを準備してから使う。既存の設定・認証・権限・hookは置き換えない。

作業前に、このrepoのAGENTS.mdと対象ディレクトリの規約を読む。依頼・現在地・必要な証拠だけを順に確認し、全skillや全資料を一括で読み込まない。

AGENTS.mdが指定するkitのrulesと、作業に合う導入済みskillを使う。指示・ツール・権限が欠けている場合は、その依存操作を止めて不足を報告する。既存の承認範囲と停止指示を保持し、指示ファイルを実行許可に置き換えない。
